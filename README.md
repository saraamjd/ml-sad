# ML-SAD — Machine-Learning Screening of Social Anxiety Disorder

Reproducible analysis code and de-identified data for the **ML-SAD** study, which
screens for **Social Anxiety Disorder (SAD)** from how people regulate emotion.
Instead of a traditional symptom checklist, respondents answer a short
situational questionnaire measuring three emotion-regulation strategies —
**Suppression**, **Avoidance** and **Reappraisal** — and machine-learning models
use those responses to flag likely SAD.

The repository covers the full pipeline:

1. **De-identification & scoring** of the raw survey exports.
2. **Psychometrics** — reliability (Cronbach's α), item–total correlations, KMO /
   Bartlett, and exploratory factor analysis of the 30-item scale.
3. **Group statistics** — MANOVA and non-parametric comparisons (Mann–Whitney U
   with rank-biserial effect sizes) of strategies between SAD and non-SAD groups
   and between sexes.
4. **Convergent validity** — correlation of the strategy scores with SPIN
   social-anxiety severity.
5. **Screening models** — k-NN, SVM (RBF), Perceptron and Random Forest, with
   cross-validated performance and a full diagnostic-test-accuracy (DTA)
   battery (sensitivity, specificity, PPV/NPV, likelihood ratios, diagnostic odds
   ratio, Youden's J), benchmarked against the SPIN self-report screener.

## Results at a glance

Repeated stratified 5-fold cross-validation on the 30 item scores
(SAD-positive = 62, SAD-negative = 42):

| Classifier    | Accuracy | Recall | F1 | ROC-AUC |
|---------------|:---:|:---:|:---:|:---:|
| KNN (k=5)     | 0.83 | 0.83 | 0.85 | 0.90 |
| SVM (RBF)     | 0.84 | 0.87 | 0.86 | 0.91 |
| Random Forest | 0.83 | 0.89 | 0.86 | 0.92 |
| Perceptron    | 0.78 | 0.79 | 0.80 | 0.85 |

Reliability: α = 0.76 (Suppression), 0.79 (Avoidance), 0.75 (Reappraisal),
0.78 (total); KMO = 0.79. Full outputs are in [`results/`](results/) and are
regenerated by the scripts below. (Exact numbers depend on scikit-learn / BLAS
versions and the random seed.)

## Quick start

```bash
git clone <your-repo-url>
cd ml-sad
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # or: pip install -e .

# Everything below runs on the shipped, de-identified data in data/.
export PYTHONPATH=src                     # if you did not `pip install -e .`
python scripts/01_psychometrics.py
python scripts/02_group_statistics.py
python scripts/03_spin_correlation.py
python scripts/04_classification.py
```

Results are written to `results/` and figures to `figures/`.

## The instrument

Ten everyday social scenarios; for each, the respondent picks the reaction that
best matches them, mapping to one of three strategies. Item columns are coded
`<scenario><strategy>` where strategy ∈ {`S` Suppression, `A` Avoidance,
`R` Reappraisal} — e.g. `3A` is the Avoidance item of scenario 3. Subscale sums
(`sum_S`, `sum_A`, `sum_R`) and normalised scores (`suppression`, `avoidance`,
`reappraisal`, `mean_maladaptive`) are derived in `preprocessing.py`.

The screening target (`sad`) is defined on **extreme groups**: SAD-positive =
clinically diagnosed **and** high self-reported stress (level 4–5); SAD-negative
= not diagnosed **and** low stress (level 1–2). Ambiguous middle responses are
left unlabelled and excluded from the supervised analyses.

## Data, privacy & ethics

The **raw** survey exports are **not** included: they contained direct
identifiers (email addresses, IP-based geolocation, names, phone numbers). Only
**de-identified** tables are published — identifiers removed and each respondent
given a salted-hash pseudonym that cannot be re-linked to the source.
`scripts/00_deidentify.py` documents exactly how the public tables were produced;
run it against a private copy of the raw files to reproduce them. See
[`data/README.md`](data/README.md) for the full data dictionary and provenance.

If you reuse the data, respect the original participant consent and any
governing ethics approval; these are self-report measures and must not be used
for individual diagnosis.
